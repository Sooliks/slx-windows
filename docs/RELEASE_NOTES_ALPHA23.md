# SLX VPN 0.1.0-alpha.23 — маршруты Windows и установленные приложения

STATUS: PARTIAL — подготовленные исходники на основе alpha.22 (`f694b51`). Публикация и установленная проверка выполняются отдельно.

- Обычный публичный трафик получает разделённые маршруты через туннель SLX. Маршруты DNS из alpha.21 сохраняются. Перед подтверждением подключения служба проверяет маршрут Windows к представительным адресам обеих половин IPv4 и, при наличии доступного публичного источника IPv6, к адресу IPv6.
- Проверка обычных маршрутов также выполняется при подтверждении связи. Если маршрут выбирает другой интерфейс, служба снимает успешный статус и переходит к восстановлению с кодом `VPN_TRAFFIC_ROUTE_FAILED`. Это проверка таблицы маршрутизации, а не измерение трафика каждого приложения или адреса.
- Диагностика обновляется во время длительного подключения. В ней отдельно указаны текущее действие интерфейса, время чтения службы, время публикации состояния и результаты проверки обычных маршрутов. Задержавшийся ответ на действие не заменяет уже полученное состояние службы: при пересечении ответов выполняется дополнительное чтение, без повторной отправки действия.
- Повторный запуск SLX показывает уже открытое окно. Повторный автозапуск в трей не создаёт второй интерфейс, который мог бы отключить общий туннель при выходе.
- Исправлен разбор установленного EXE, если в его пути есть запятая. Сохранённые приложения Codex / ChatGPT обновляются по текущему зарегистрированному пакету пользователя, когда Windows подтверждает его наличие; при ошибке поиска прежний выбор не подменяется догадкой.
- Для включённых приложений служба согласует точный регистр установленного пути между Windows-защитой и ядром VPN. Тот же список используется при подключении, изменении выбора и восстановлении. Неподтверждённые пути, перенаправленные папки и несовпадение идентичности EXE отклоняются с понятным сообщением; выбор не расширяется на одноимённые программы.

Переключатели действуют на новые соединения. Для проверки Telegram полностью выйдите из него через трей и запустите заново. Подтверждения устранения проблемы на ПК друга и влияния на CS2 пока нет; Wi-Fi не установлен как причина.

Службу и интерфейс нужно обновлять вместе официальным установщиком. Подписка и настройки сохраняются. Сайт в этой итерации не меняется; его ссылка на загрузку может обновляться независимо из-за кэша.
