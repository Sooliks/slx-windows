# SLX VPN 0.1.0-alpha.16 — служба и повторное использование обновлений

STATUS: PARTIAL — предварительная версия Windows 10 / 11.

Убраны подписи «Использовать VPN / Без VPN» возле приложений. Выбор показывает переключатель, названиям доступно больше места.

Служба удаляет записи выполненных команд старше 10 минут. Это устраняет бессрочное заполнение лимита 4096 записей, после которого новые подключения отклонялись с IPC_RECEIPT_LIMIT. Ограничение количества и проверка повторов внутри окна сохранены. Был ли это причиной конкретного сбоя после долгой работы, пока не установлено.

Уже скачанный установщик предложенной версии используется повторно, если находится в защищённой папке обновлений SLX и совпадает с опубликованными размером и SHA-256. Повреждённый файл скачивается заново. Перед запуском проверка сохраняется.

Для исправления службы установите обновление целиком. Настройки и подписка сохраняются; серверы, сайт и зависимости не меняются.

По просьбе владельца полный verify и тесты для этого выпуска не запускаются. Выполняется сборка и штатная проверка упаковки; системная приёмка, воспроизведение исходного сбоя и установка/откат остаются открытыми. Добавленные регрессионные тесты не считаются пройденными.
