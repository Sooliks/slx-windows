# SLX VPN 0.1.0-alpha.7 — CS2 и Rust

STATUS: PARTIAL — предварительная версия для Windows 10 / 11, установщик без подписи.

- Автоматическое добавление установленных Counter-Strike 2 и Rust по Steam-ярлыкам .url рабочего стола.
- Чтение локальных libraryfolders.vdf и appmanifest учитывает несколько дисков и находит игровые EXE; Steam, URL и игры при этом не запускаются.
- Rust.exe и RustClient.exe объединяются в одну карточку/переключатель, сохраняя оба точных пути. CS2 использует cs2.exe.
- Параметры команд, сторонние URL, переходы за пределы игровой папки и отсутствующие EXE не принимаются. Ручное добавление и обычные .lnk остаются.
- Включены исправления alpha.6: видимый поиск и фоновая загрузка иконок; alpha.5: восстановление и защита трафика, DNS, группы и тонкая прокрутка.

Проверено на Windows 11: 168 unit/Windows проверок и один расширенный WPF-сценарий; локальный поиск действительно нашёл CS2 и оба EXE Rust на двух библиотеках Steam. Игры и античит не запускались, игровое соединение не проверено.
Это поддержка указанных Steam-ярлыков, а не обещание обнаружить все игры любого магазина. Для других игр остаётся выбор EXE.
Сетевой runtime и политика защиты не меняются относительно alpha.5; общая Windows 10/IPv6/HTTP3/clean-VM приёмка остаётся открытой.
