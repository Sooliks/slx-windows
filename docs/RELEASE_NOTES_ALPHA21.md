# SLX VPN 0.1.0-alpha.21 — готовность маршрутов DNS

STATUS: PARTIAL — предварительная версия Windows 10 / 11. Наличие исходников не означает публикацию установщика.

- Добавлены точные маршруты двух уже настроенных DNS-адресов на адаптер SLX. Они принадлежат туннелю SLX и используют существующий механизм его создания и очистки; настройки DNS физических адаптеров и чужие маршруты не переписываются.
- Проверка подключения ограниченно ожидает появления нужного маршрута вместо трёх мгновенных отказов. Сохраняются общий лимит времени, отмена и обязательная проверка обычного маршрута Windows до DNS-запроса и после ответа.
- Для неподтверждённого маршрута добавлен отдельный код `VPN_DNS_ROUTE_FAILED` и понятное сообщение. «Помощь → Скопировать диагностику» дополняет результат длиной префикса и метрикой маршрута; адреса, имена адаптеров и личные данные в текст не включаются.

Полученный отчёт alpha.20 показывает `RouteMismatch / OtherInterface / 0 ms` во всех трёх попытках: запрос DNS не отправлялся, потому что выбранный Windows маршрут не принадлежал SLX. Отчёт не определяет конкретный конкурирующий адаптер и не доказывает сбой Hysteria2 или DNS-сервера. Исправление требует проверки на ПК друга и на рабочем ПК владельца.

Защита трафика, проверка полного ответа DNS, HTTPS-серверы DNS и восстановление после неудачной первой попытки сохраняются. При выборе чужого маршрута подключение не объявляется успешным. Проверка Wi-Fi, CS2, отключения и сохранности чужих маршрутов остаётся частью установленной приёмки.

Установщик обновляет службу и интерфейс вместе. Перед установкой отключите VPN, дождитесь подтверждённого отключения и выйдите из SLX через трей. Затем установите alpha.21 поверх текущей версии. Настройки и подписка сохраняются.
