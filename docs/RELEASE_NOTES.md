# SLX VPN 0.1.0-alpha.5 — Windows 10 / 11

STATUS: PARTIAL — предварительная версия, установщик без подписи.

- Библиотека больше не предлагает типовые деинсталляторы как обычные программы. Фильтр общий для всех производителей и источников списка: запущенные программы, установленные приложения и каталог.
- Обычные приложения сохраняются: Steam.exe остаётся, uninstall.exe / unins000.exe / uninst.exe и варианты исключаются. Фильтр проверяет имя самого файла, а не папку; сохранённые пользовательские правила не удаляются.
- Добавлена возможность установки на Windows 10 начиная со сборки 19041. Ранее установщик блокировал все системы ниже Windows 11.
- В пользовательских подписях указано Windows 10 / 11 без архитектуры.

Проверено на Windows 11: locked restore, Release build, 140 unit/Windows проверок и один WPF-сценарий.
Реальная установка, подключение и UI на Windows 10 ещё требуют отдельной приёмки. Целевая совместимость не равна завершённому тесту на этой ОС.
.NET и официальный Wintun входят в комплект. Обновляйте поверх установленной версии: ID устройства и настройки сохраняются.
Сетевые протоколы, серверы, Happ и привязка подписки этим релизом не меняются.

Сохраняются ограничения alpha.4: нет kill switch, общий DNS в выбранном режиме, незавершённая UDP/IPv6/HTTP3 и clean-VM приёмка.
Подробности: docs/VERIFICATION.md и docs/COMPATIBILITY.md.
