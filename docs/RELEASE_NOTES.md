# SLX VPN 0.1.0-alpha.3 — Windows 11 x64

STATUS: PARTIAL — ранний открытый клиент, неподписанный установщик.

- Исправлен воспроизведённый обрыв TLS при обращении к IPv6-адресам сайтов. Владелец подтвердил, что YouTube и плеер Twitch заработали в установленном кандидате.
- Библиотека приложений с локальными иконками, поиском и добавлением одним нажатием. Ручной выбор .exe сохранён.
- Добавление, удаление и переключение приложений применяются автоматически. Текущее ядро кратко переподключает VPN; несколько быстрых изменений объединяются.
- Потерянный ответ не считается успехом и не вызывает слепой повтор. Отключение отменяет ещё не начатое обновление.

Hysteria2 и VLESS остаются доступны. Серверы, Happ, ссылки подписок и привязка устройств не изменялись.
Обновляйте установщиком поверх прежней версии: настройки и собственный ID устройства сохраняются.

Проверено: сборка без предупреждений; 120 unit/Windows-проверок и один расширенный WPF-сценарий.
Реальные локальные A/B-пробы повторили IPv6 TLS-обрыв и HTTP 200 после восстановления имени на обоих протоколах.
Установка кандидата: exit 0, служба Connected/ProbePassed=true, пользователь подтвердил воспроизведение YouTube/Twitch.

Ограничения: нет kill switch, DNS выбранных приложений остаётся общим, существующие соединения не мигрируют бесшовно.
Нет обещания полной поддержки IPv6/ECH/HTTP3: HTTP3 в диагностике не прошёл, UDP-изоляция выбранных процессов требует дальнейшей проверки.
Сон/смена сети, чистая VM, несколько пользователей и полная приёмка Windows 10 не завершены.
Подробности: docs/VERIFICATION.md и docs/NETWORK_DIAGNOSIS.md.
