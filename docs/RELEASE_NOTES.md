# SLX VPN 0.1.0-alpha.30 — Claude и обновление путей приложений

- Один переключатель «Claude» охватывает Desktop, встроенный Claude Code и известные вспомогательные EXE. Ручной дубль Code объединяется с Desktop; сохраняется выбор Desktop.
- Пока SLX открыт или находится в трее, новые пути выбранных версий обновляются без переподключения VPN. Для Claude обновление Desktop и первое появление Code дополнительно отслеживаются по событиям файловой системы.
- Автообновление действует для известных семейств Claude, Codex / ChatGPT, Discord и Roblox. Для произвольного вручную добавленного EXE сохраняется точный выбранный путь.

Поддерживаемые локальные пути определяются для текущего пользователя. Нативные проверки путей и лимит
128 правил сохранены. Отдельно установленный Claude Code CLI остаётся отдельным приложением.
Сайт, серверы, подписка, Wintun и формат обновления не меняются.

[Проверки и ограничения](https://github.com/Sooliks/slx-windows/blob/v0.1.0-alpha.30/docs/VERIFICATION.md)

## Предыдущий выпуск 0.1.0-alpha.29 — восстановление и понятный выбор приложений

- После успешной проверки VPN клиент больше не ждёт недоступный второй контрольный адрес. Отмена подключения сохраняет приоритет; бюджеты проверок не увеличены.
- Потеря физического интерфейса переводит подключение в проверку с сохранением общего процесса и защиты. Подтверждённая смена интерфейса вызывает перепривязку. При восстановлении отдельно проверяется ответ локального управления Xray.
- Диагностика различает запущенный транспорт, последнюю неудачную попытку и следующий вариант. История сохраняет транспорт каждой попытки, время свежей успешной проверки и отдельные наблюдения локального/физического пути.
- Общий исполняемый файл Riot называется Riot Client независимо от имени игрового ярлыка. Поиск находит программы по имени, EXE, пути и алиасам, включая уже добавленные. Пересечения файлов между группами показаны рядом с выключенным переключателем; прежние пути, ID и независимый выбор сохраняются.

Проверено локально: Release-сборка, 821 основной тест и составной WPF-тест с RU/EN-рендерами, 24 теста выпуска,
18 runtime-контрактов. На настоящем закреплённом Xray в loopback-стенде проверены сохранение direct TCP/UDP при
остановке отдельного ядра, восстановление выбранных потоков, ответ локального управления и DNS обоих режимов.

STATUS: PARTIAL по установленной системной приёмке. Loopback не заменяет проверку реального TUN/WFP, переключения
Wi-Fi/Ethernet, публичных транспортов, обновления alpha.28 → .29 и игр на ПК друга. Причина его эпизодов не доказана.
Невыбранные программы выходят напрямую, но ещё зависят от общего локального TUN; его необходимое полное
восстановление может прервать соединения. Этот выпуск не обещает отсутствия любых обрывов.

Серверы, сайт, DNS-политика, драйвер и внешние зависимости не меняются. Защита выбранного трафика сохраняется;
автоматического выпуска через direct при отказе VPN нет. Интерфейс и служба обновляются вместе, формат настроек,
подписка и ID установки сохраняются. Существующее встроенное обновление и отдельная настройка автоустановки остаются.
