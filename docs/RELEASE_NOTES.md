# SLX VPN 0.1.0-alpha.10 — проверка перед переподключением

STATUS: PARTIAL — предварительная версия для Windows 10 / 11, установщик без подписи.

Раньше один неудачный запрос проверки приводил к полному перезапуску туннеля. Теперь служба сначала повторяет проверку и обращается к независимому адресу через тот же VPN. Если связь подтверждена, работающий туннель и время подключения сохраняются. Если проверки не проходят, запускается обычное автоматическое восстановление.

Во время неподтверждённого состояния приложение показывает восстановление, а не успешное подключение. Защита выбранного трафика остаётся включённой. Падение ядра или потеря адаптера по-прежнему запускает восстановление сразу. Проверки готовности при первоначальном подключении, WFP, DNS и серверы не меняются.

Для диагностики служба хранит в памяти категории результатов, HTTP-коды, длительность и счётчики проверок. Ключи, ссылки, списки программ и тексты сетевых ошибок в эти сведения не попадают. Необязательное поле HealthCheck совместимо с IPC v2; приложение и служба обновляются установщиком вместе.

Это исправление преждевременного перезапуска, а не доказанное устранение всех причин обрывов. Поведение Happ после сна на телефоне исследуется отдельно.
