# SLX VPN 0.1.0-alpha.8 — актуальная справка

STATUS: PARTIAL — предварительная версия для Windows 10 / 11, установщик без подписи.

Исправлена устаревшая RU/EN подпись в «Помощи»: она теперь описывает действующую защиту публичного трафика при сбое VPN, автоматическое восстановление и явное отключение. Сетевой код не меняется.
Сохранены CS2/Rust и Steam-ярлыки, видимый поиск с фоновой загрузкой иконок, объединённые пути приложений, тонкая прокрутка у края окна и все исправления alpha.5–7.

Проверено: 168 unit/Windows проверок и один расширенный WPF-сценарий. Пользователь подтвердил появление обеих игр с иконками и ранее — объединение Claude/новую прокрутку. Сетевые аварийные проверки alpha.5 описаны в docs/VERIFICATION.md.
Игровое соединение, Windows 10, полная IPv6/HTTP3/clean-VM приёмка остаются открытыми. Обновление сохраняет ID, ссылку и настройки; серверы и Happ не меняются.
