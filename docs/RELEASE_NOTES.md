# SLX VPN 0.1.0-alpha.2 — Windows x64

Открытый исходный код / open source. Исправления первого выпуска и более простой выбор приложений.

- Исправлена потеря ответов службы: локальный протокол v2 подтверждает чтение ответа перед закрытием канала. Проверки SID, прав и подлинности службы сохранены.
- Переподключение ожидает завершения удаления собственного TUN-адаптера Windows. Чужие адаптеры не удаляются.
- Исправлены названия профилей, лишние разделители в режиме всего компьютера, меню трея и выход при недоступной службе.
- Сохранённая подписка однократно обновляется при запуске; старый список сохраняется при ошибке. Обновление не подключает VPN и не меняет работающий туннель.
- Приложения можно быстро выбрать из списка запущенных программ с поиском. Ручной выбор .exe сохранён.
- RU/EN, темы SLX/Terminal и собственная привязка устройства сохранены.

STATUS: PARTIAL. Это prerelease; подробная область проверки — docs/VERIFICATION.md.
Установка обновляет интерфейс и службу вместе: старый интерфейс необходимо закрыть.

Встроенный .NET 10.0.13; отдельная установка runtime не нужна.
Установщик и SLX пока не подписаны; Wintun имеет подпись производителя.
Обновление сохраняет ID установки и настройки; повторно создавать устройство ради обновления не нужно.
Для первого импорта создайте отдельное устройство SLX или штатно перенесите привязку из Happ.

Kill switch отсутствует: при сбое ядра возможен прямой трафик.
DNS выбранных приложений использует общий резолвер Windows напрямую.
Полная проверка IPv6, сна/смены сети, изоляции приложений и чистой VM ещё не завершена.
Windows 11 x64; Windows 10 не заявлен. Production-серверы и Happ не перенастраиваются.

Исходники SLX: MIT; Xray и Wintun имеют собственные лицензии.
SHA256SUMS.txt содержит контрольные суммы; provenance.json — точный коммит и происхождение компонентов.
Архивы source-full/source-changed сохраняют пути; удаления перечислены отдельно в DELETIONS.txt.
