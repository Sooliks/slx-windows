SLX VPN for Windows — открытый исходный код / open source.

Первая alpha: импорт SLX-ссылки, Hysteria2 и VLESS/XHTTP, выбор .exe для VPN, режим всего ПК, RU/EN, темы SLX/Terminal и переподключение.

Установка: скачайте setup.exe. Установка сетевой службы требует подтверждения Windows; обычный интерфейс работает без повышения прав.
Встроенный .NET 10.0.13, отдельная установка runtime не нужна. Установщик и код SLX пока не подписаны; Wintun имеет подпись производителя.
Для подключения создайте отдельное устройство в SLX или штатно перенесите привязку из Happ.

Проверено: 93 теста, сборка без предупреждений, реальный локальный TUN-тест разделения двух EXE по TCP и UDP; очистка адаптера и неизменность основных маршрутов подтверждены. Это ещё не проверка трафика через реальные серверы.

STATUS: PARTIAL. Это prerelease; системная приёмка указана в docs/VERIFICATION.md.
Kill switch отсутствует: при сбое ядра возможен прямой трафик. DNS выбранных приложений использует общий резолвер Windows напрямую.
Поддерживается Windows 11 x64; Windows 10 не заявлен. Production-серверы не менялись.

Исходники: MIT; Xray и Wintun распространяются со своими лицензиями.
SHA256SUMS.txt содержит контрольные суммы; provenance.json — версии и происхождение компонентов.
