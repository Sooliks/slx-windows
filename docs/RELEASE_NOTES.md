# SLX VPN 0.1.0-alpha.5 — восстановление и библиотека

STATUS: PARTIAL — предварительная версия, установщик без подписи.

- Защита выбранных приложений при потере VPN: постоянные правила Windows блокируют публичный трафик вне собственного TUN. В режиме всего компьютера защита применяется ко всему публичному трафику; ядру и сетевой службе разрешено восстановить VPN. Локальная сеть остаётся доступной.
- Повторные подключения продолжаются с паузами от 2 до 60 секунд. Остановка службы сохраняет защиту и зашифрованное намерение подключения. Кнопка «Отключиться» снимает защиту; удаление приложения штатно очищает собственные правила.
- Публичный DNS из TUN использует HTTPS через VPN без прямого DNS fallback. Это общий Windows DNS, а не изоляция DNS по приложениям. Проверка DNS выполняется до статуса «Подключено».
- Общая запись Codex / ChatGPT включает основной EXE и известные помощники по точным локальным путям. Нет правил для всех Node/PowerShell/WebView процессов.
- Библиотека читает локальные ярлыки рабочего стола и меню «Пуск» без запуска программ. Удаляторы и ProgramData Package Cache исключены. Иконки и ручное добавление сохранены; списки программ не отправляются на сервер.
- Установщик допускает Windows 10 начиная со сборки 19041 и Windows 11. Реальная приёмка на Windows 10 остаётся открытой.

На Windows 11 проверены сборка, 156 unit/Windows тестов и один WPF-сценарий; нативная IPv4 TCP/UDP блокировка выбранного EXE, независимый контроль, восстановление службы и три падения ядра. Пользователь подтвердил YouTube и наличие Codex / ChatGPT.
Полная IPv6/HTTP3, существующие долгоживущие потоки, sleep/Wi-Fi/смена интерфейса, clean VM и Windows 10 требуют отдельной приёмки. См. docs/VERIFICATION.md.
Обновляйте поверх предыдущей версии: ссылка, ID установки и настройки сохраняются. Серверы, Happ и привязка устройства не меняются.

Приложения с одинаковым названием объединяются в одну карточку и переключатель; все найденные пути сохраняются. Публичный DNS вне TUN блокируется и при восстановлении; общий DNS незадействованных программ в это время тоже может ждать VPN.

Прокрутка страниц вынесена к правому краю окна. Тонкий бегунок сохраняет широкую область захвата; hover не меняет размеры.
