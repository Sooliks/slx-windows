# SLX VPN 0.1.0-alpha.20 — устойчивый DNS и диагностика подключения

STATUS: PARTIAL — предварительная версия Windows 10 / 11. Наличие исходников не означает публикацию установщика.

- Исправлен выбор DNS-серверов: прежняя настройка Xray фактически оставляла только первый из двух. Теперь оба существующих HTTPS-сервера могут ответить через VPN; медленный или недоступный первый сервер не блокирует обращение ко второму.
- Проверка DNS сохраняет ограничение времени и требует подтверждённый ответ. Перед запросом и принятием ответа проверяется, что обычный маршрут Windows ведёт в адаптер SLX; адреса и настройки других адаптеров не меняются.
- Ответ DNS проверяется целиком. Одного заголовка с заявленным количеством ответов недостаточно для состояния «Подключено».
- Для `VPN_DNS_FAILED` добавлено отдельное понятное сообщение. «Помощь → Скопировать диагностику» теперь показывает результаты до трёх попыток: таймаут, ошибку сокета, код DNS или неподходящий маршрут. Личная ссылка, адреса серверов, адаптеров и список программ не попадают в текст.

Сохраняются сетевое восстановление alpha.18 и исправления обновления alpha.19. Правила WFP, драйвер, ядро Xray, сторонние зависимости и формат сохранённых настроек не меняются. Оба DNS-сервера остаются HTTPS-серверами через VPN; возврата к обычному DNS вне VPN нет.

Дефект выбора DNS воспроизведён на закреплённом ядре Xray. Скриншот друга подтверждает этап отказа, но не доказывает, что причиной на его ПК была недоступность первого DNS. Работа на этом ПК, через Wi-Fi и в CS2 требует отдельной проверки.

Установщик обновляет службу и интерфейс вместе. Перед установкой отключите VPN, дождитесь подтверждённого отключения и выйдите из SLX через трей. Затем установите новую версию поверх текущей.
