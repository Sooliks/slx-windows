# SLX VPN 0.1.0-alpha.4 — Windows 11 x64

STATUS: PARTIAL — ранний открытый клиент, неподписанный установщик.

- Исправлен подтверждённый обрыв ChatGPT и Claude: собственный виртуальный IPv6-адрес больше не выбирается Windows как обычный исходящий адрес. Физические интерфейсы и глобальные настройки IPv6 не меняются.
- Общий каталог из 18 популярных программ приходит с SLX; встроенная копия доступна без сети. Обнаружение установленных программ и их иконок происходит локально. Список приложений компьютера не отправляется на сервер.
- Можно добавить программу, которая сейчас не запущена. Если путь не найден автоматически, доступен выбор .exe.
- Колесо мыши над библиотекой прокручивает страницу. На главной появились переключатели приложений; выключенная карточка остаётся на месте.
- Показаны длительность текущего подключения, действующий протокол, число выбранных приложений и время последнего ответа службы. Объём трафика и скорость пока не измеряются.

Владелец подтвердил ChatGPT и Claude после установки кандидата и нового подключения.
Ранее подтверждены YouTube/Twitch и автоматическое применение добавленного Chrome.
Изменение правил кратко переподключает туннель; быстрые изменения объединяются.

Hysteria2 и VLESS доступны. Обновляйте установщиком поверх прежней версии; настройки и ID сохраняются.
Серверы, Happ, ключи и привязка устройств этим клиентским релизом не меняются.

Проверено: locked restore, Release build без предупреждений; 128 unit/Windows проверок и расширенный WPF-сценарий.
Ограничения: нет kill switch; DNS выбранных приложений общий; существующие соединения не мигрируют бесшовно.
Полные IPv6/ECH/HTTP3 и UDP-изоляция выбранных процессов не приняты; сон/смена сети, чистая VM и несколько пользователей не проверены полностью.
Подробности: docs/VERIFICATION.md, docs/NETWORK_DIAGNOSIS.md.
