# SLX VPN 0.1.0-alpha.14 — изменения приложений без общего переподключения

STATUS: PARTIAL — предварительная версия для Windows 10 / 11.

Добавление, включение, выключение и удаление приложений больше не отправляют команду общего переподключения.
Служба обновляет правила при работающем ядре и сохраняет туннель и время подключения. Удаление уже выключенной
программы или быстрые переключения, вернувшие прежний набор, вообще не меняют сетевые правила.

Несколько быстрых действий объединяются в одно применение. В режиме «Весь ПК» изменения списка остаются локальными.
Смена способа подключения или режима по-прежнему требует переподключения; выключение последнего выбранного приложения
отключает VPN. Ручная кнопка переподключения сохраняет своё прежнее действие.

Новый маршрут применяется к новым соединениям. Уже открытый сеанс изменённого приложения может потребовать
переподключения самого приложения. SLX не закрывает программы. Общая служба DNS сохраняет прежнюю модель.

Новые приложения получают защиту до смены маршрутов. Из правил Windows меняются только затронутые приложения;
правила остальных, DNS и исключения туннеля сохраняются. Для горячего обновления используется закрытый канал через
существующий защищённый паролем локальный вход. Отдельного открытого порта управления нет.

При потере ответа SLX проверяет применённую версию правил и не повторяет команду вслепую. Ошибка применения
не запускает общий перезапуск VPN; интерфейс отдельно показывает неопределённость изменений. Защита сохраняется.

Обновляйте приложение и службу вместе установщиком. Старые службы не поддерживают новую команду и не получают
автоматического обходного переподключения. Настройки, подписка и ID установки сохраняются. Серверы, аккаунты,
протоколы и зависимости не меняются. Установщик остаётся без подписи; Wintun сохраняет подпись производителя.

Сохранение процесса и адаптера не гарантирует непрерывность всех существующих потоков: Windows может переавторизовать
соединения после изменения ALE-политики. Установленная системная приёмка и Windows 10 остаются открытыми.
Полный verify: 379 unit/Windows проверок и расширенный WPF-сценарий, без ошибок, пропусков и предупреждений.
Отдельный тест с настоящим закреплённым Xray проверил защищённый API, две замены правил и сохранение открытого
локального TCP-сеанса; он не использует TUN и не заменяет установленную системную приёмку.
Точные выполненные проверки и ограничения: [VERIFICATION.md](VERIFICATION.md).
