# SLX VPN 0.1.0-alpha.9 — автозапуск и диагностика

STATUS: PARTIAL — предварительная версия для Windows 10 / 11, установщик без подписи.

Исправлено состояние, когда автозапуск отмечен в SLX, но запись Windows отсутствует или ведёт к старому файлу. Обычный запуск приложения восстанавливает сохранённый выбор; вход в Windows запускает SLX в трее. Ошибки регистрации объясняются на русском и английском. Отключённые самой Windows записи не включаются принудительно.

Служба сохраняет в памяти число автоматических восстановлений, последнюю причину и время. Эти безопасные сведения остаются доступны после восстановления: без ключей, ссылок, списков программ и журналов посещений. Это диагностика, а не исправление ещё не установленной причины обрывов. Поле Recovery необязательное в IPC v2; UI/служба обновляются установщиком вместе.

Сетевые маршруты, защита трафика, таймеры восстановления, серверы и Happ не меняются. Полная приёмка Windows 10, перезагрузки и системных сценариев остаётся открытой. Проверки текущего кандидата записываются в docs/VERIFICATION.md.
