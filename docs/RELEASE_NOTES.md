# SLX VPN 0.1.0-alpha.11 — обновления, диагностика и интерфейс

STATUS: PARTIAL — предварительная версия для Windows 10 / 11, приложение и установщик без подписи.

## Подключение и восстановление

Если Windows ещё готовит сетевую защиту при запуске без активного VPN, служба повторит свою начальную очистку с паузами. Интерфейс покажет подготовку и дождётся подтверждённой готовности перед автоподключением. Ошибка чтения сохранённого намерения не разрешает удалять защиту.

Новые пути Discord/Roblox проверяются также при запуске службы после перезагрузки, до автоматического восстановления. Один проверенный список используется для защиты и запуска ядра; изменённые зашифрованные настройки сохраняются после успешного применения защиты.

Исправлен подтверждённый сценарий: сохранённый путь к удалённой версии Discord или Roblox мешал Windows создать правило защиты и давал общий `TRAFFIC_PROTECTION_FAILED`. Перед подключением SLX проверяет известные соседние версии этих приложений и включает их отдельными точными путями. Существующие пути сохраняются; неразрешённый путь не пропускается ради успешного подключения. Если Windows всё ещё не находит файл или запрещает доступ, приложение показывает соответствующую подсказку. Другие ошибки WFP содержат безопасный код этапа и числовой результат Windows без путей, ключей и текстов системных ошибок.

Ожидаемая ошибка восстановления после запуска службы больше не мешает открыть локальное управление. Сохранённое намерение подключиться остаётся доступно для обычных повторов. Неисправная RPC-сессия WFP закрывается и открывается заново при следующей попытке; постоянные правила защиты не снимаются. Очистка ограничена фильтрами SLX и учитывает отключённые фильтры. Чужие VPN, адаптеры и правила не удаляются.

Явное отключение доступно даже при заполненном кэше подтверждений IPC. После успешно подтверждённого отключения без активной защиты освобождается владелец службы, чтобы следующий единственный пользователь Windows мог подключиться со своей учётной записью. Неуспешный или неопределённый результат не передаёт управление другому пользователю. Одновременная маршрутизация нескольких Windows-пользователей по-прежнему не поддерживается.

## Обновления

SLX проверяет новые версии при запуске и затем раз в шесть часов, предлагает обновление и позволяет напомнить завтра. Автоматическую проверку можно отключить. Загрузка и запуск установщика требуют отдельных действий пользователя. Установка допускается после свежего ответа службы об отключённом VPN и неактивной защите; изменение подключения блокируется на время проверки и передачи установщику.

После успешного запуска установщика окно SLX закрывается, чтобы VPN нельзя было включить во время ожидания мастера. При отмене мастера откройте SLX снова. Отказ от UAC оставляет приложение открытым и допускает явный повтор; удалённый или повреждённый подготовленный файл можно скачать заново.

Источником служат HTTPS-релизы публичного `Sooliks/slx-windows` на GitHub. Размер и SHA-256 проверяются после загрузки и перед запуском. Контрольная сумма из того же репозитория подтверждает целостность, а не подпись издателя: установщик остаётся без подписи, метка интернет-зоны сохраняется, подтверждение UAC не обходится. Для применения нужен опубликованный релиз с ожидаемым установщиком и `SHA256SUMS.txt`; наличие кода проверки само по себе не означает публикацию такого релиза.

## Интерфейс

В настройках автозапуска появился отдельный переключатель подключения VPN, включённый по умолчанию при разрешённом автозапуске. После входа в Windows SLX дождётся сети, службы и сохранённого профиля и выполнит одну безопасную попытку. Обычный ручной запуск не включает VPN автоматически. Уже активное подключение сохраняется; ручное отключение отменяет ожидающий автозапуск. Неопределённый ответ службы не повторяется вслепую. Для новой IPC-команды приложение и служба обновляются вместе; старой службе не отправляется опасный повтор обычного connect.

Обновлены поверхности, контраст, основные действия и карточки состояния в цветах сайта. Фон использует статичную нативную геометрию разрезанного X, без таймеров анимации и вымышленных показателей трафика. При узком окне меню превращается в компактную панель значков с подсказками и доступными именами. Сохранены темы Olive и Terminal, RU/EN, системные элементы управления и фактические состояния службы.

По отзыву владельца о 27-дюймовом Full HD мониторе усилены шрифты: плотнее основной текст и пояснения, жирнее заголовки, крупнее прежние мелкие подписи. Режим Ideal/Grayscale сглаживает текст без принудительного пиксельного Display/ClearType. Подписи режимов проще: «Приложения» и «Весь ПК». Системные Segoe UI и Consolas сохранены без поставки файлов шрифтов.

До подключения нет пустых карточек с прочерками: статистика появляется только после подтверждённого соединения. При восстановлении или неизвестном состоянии остаются понятный статус и управление; отсутствующий протокол не подменяется вымышленным значением.

## Проверки и ограничения

`scripts/verify.ps1` завершился с кодом 0: locked restore, Release build без предупреждений, 285 unit/contract tests и одна WPF-проверка, без пропусков. Первоначальная попытка в ограниченной среде не прошла из-за доступа к NuGet; успешный повтор выполнен с разрешённым выходом из ограничений среды. Подробности команд и ограничений — в VERIFICATION.md.

Точная причина сбоя на компьютере друга не установлена. В этой итерации не выполнялись проверка установленной службы, настоящий перезапуск Windows, совместная работа с ExitLag, реальные TUN-маршруты или установка обновления поверх рабочей версии. Сборка, read-only вызов определения ID приложения и WPF fixture не заменяют эти проверки. Production, серверы, подписки и живые сетевые настройки не менялись.
