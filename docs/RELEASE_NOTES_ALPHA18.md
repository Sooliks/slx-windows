# SLX VPN 0.1.0-alpha.18 — подключение и восстановление сети

STATUS: PARTIAL — предварительная версия Windows 10 / 11. Исходники подготовлены; наличие этой записи не означает публикацию установщика.

- Статус и «Отключиться» обслуживаются, пока другое подключение ждёт ответа сети. У службы четыре ограниченных канала; проверки владельца Windows, защиты канала и повторных запросов сохранены.
- «Отключиться» остаётся доступным после потерянного ответа на первое подключение, в состоянии остановки и при недоступной сохранённой подписке. Неизвестное состояние не выдаётся за работающий VPN.
- Окончательно неудачная новая попытка из подтверждённо отключённого состояния отменяется с очисткой её сетевых ограничений. Код исходной ошибки сохраняется. Уже работавший защищённый VPN и неизвестный результат сохраняют защиту до восстановления или явного отключения.
- Неудачная очистка после отключения повторяется с паузами; служба не запускает новый туннель поверх незавершённой очистки.
- Исходящий интерфейс выбирается по маршруту Windows к серверу VPN, а не по предпочтению Wi-Fi внутри ядра. Физические маршруты и настройки других VPN не изменяются.
- При запуске доступность подтверждается через один из двух проверяемых HTTPS-адресов. Проверки TUN и DNS остаются обязательными.
- Добавлена команда аварийного отключения `scripts/repair-network.ps1` для администратора. Она работает только с установленной службой и защитой SLX; не сбрасывает общий firewall и не удаляет адаптеры.
- Исправлены устаревшие lock-файлы интерфейса/UI-тестов. Версии сторонних зависимостей сохранены.

Общий публичный DNS Windows по-прежнему защищается через VPN. При восстановлении это может влиять на невыбранные приложения; режим «Приложения» теперь прямо сообщает об этом. Полная независимость CS2/Steam, работа с ExitLag и результат на конкретных проблемных ПК требуют проверки установленной версии.

Приложение и служба обновляются вместе установщиком. Подписка, настройки и ID установки сохраняются; серверные изменения не нужны. Сборка, тесты и выпуск: [UPDATE_ALPHA18_RU.md](UPDATE_ALPHA18_RU.md). Фактически выполненные проверки: [VERIFICATION.md](VERIFICATION.md).
