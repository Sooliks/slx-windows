# SLX VPN 0.1.0-alpha.19 — проверка обновлений на медленном соединении

STATUS: PARTIAL — предварительная версия Windows 10 / 11. Запись об изменениях сама по себе не означает публикацию установщика.

- Список версий GitHub запрашивается со сжатием gzip. На проверенном ответе объём передачи уменьшился со 149 771 до 23 874 байт. Если сервер возвращает обычный несжатый ответ, он также поддерживается.
- Общий лимит проверки версии и контрольных сумм увеличен с 15 до 30 секунд. Чтение ответа и распаковка остаются ограниченными; отмена запроса пользователем сохраняется.
- Интерфейс отдельно сообщает о превышении времени проверки и о некорректных данных обновления. Технические ответы сервера и исключения не выводятся пользователю.
- Сохранены проверка точного репозитория, HTTPS, разрешённых перенаправлений, размера и SHA-256 установщика, а также отдельное подтверждение скачивания и установки.

Выпуск включает сетевые исправления alpha.18. Служба, маршрутизация, DNS, драйвер, подписка и формат настроек в alpha.19 не изменяются; сторонние зависимости не обновляются.

Если проверка обновлений в alpha.17/18 не завершается, установите alpha.19 вручную через файл этого релиза. Новый способ проверки появится после обновления самого приложения. Перед установкой отключите VPN, дождитесь подтверждённого отключения и выйдите из SLX через трей.

Сборка и публикация: [UPDATE_ALPHA19_RU.md](UPDATE_ALPHA19_RU.md). Фактические проверки и ограничения: [VERIFICATION.md](VERIFICATION.md).
