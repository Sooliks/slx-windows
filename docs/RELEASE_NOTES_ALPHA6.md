# SLX VPN 0.1.0-alpha.6 — загрузка библиотеки

STATUS: PARTIAL — предварительная версия для Windows 10 / 11, установщик без подписи.

- При открытии «Приложения» видны подпись «Ищем приложения и загружаем иконки…» и индикатор поиска.
- UI получает время на отрисовку до начала работы; извлечение иконок выполняется в фоновой задаче и сохраняется в локальном кэше.
- Кнопка обновления недоступна во время поиска. Пустой результат появляется только после его завершения; ошибка сохраняет предыдущий список и показывает сообщение.
- Все возможности alpha.5 сохранены: защита при потере VPN, восстановление, DNS через VPN, объединённые EXE-пути, ярлыки рабочего стола и тонкая прокрутка у края.

Проверено на Windows 11: locked restore, Release build, 156 unit/Windows проверок и один расширенный WPF-сценарий, включая незавершённый поиск, завершение и ошибку. Сетевой runtime не меняется относительно alpha.5; его аварийные проверки записаны в docs/VERIFICATION.md.
Windows 10, clean VM, полная IPv6/HTTP3 и sleep/network приёмка остаются открытыми. Это prerelease.
Обновление сохраняет ссылку, ID установки и настройки. Серверы и Happ не меняются.
