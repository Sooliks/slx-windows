# SLX VPN 0.1.0-alpha.12 — быстрая библиотека приложений

STATUS: PARTIAL — предварительная версия для Windows 10 / 11.

## Приложения доступны во время поиска

SLX сохраняет ранее найденные приложения локально и показывает их при следующем запуске. Список обновляется в фоне:
новые программы появляются по мере готовности отдельных источников. Поиск, выбор приложений и ручной выбор `.exe`
доступны во время обновления. Повторное открытие раздела в течение пяти минут использует недавнюю успешную проверку;
кнопка «Обновить список» запускает новую.

Иконки подгружаются отдельно, с готовой заглушкой с первого кадра. Их извлечение больше не задерживает появление
приложений и не выполняется в UI-потоке. Повторные запросы объединяются; число одновременных поисков и загрузок ограничено.

Сохранённые данные, фоновая проверка и время последнего полного обновления различаются в интерфейсе. Если часть
проверки не удалась, доступные карточки остаются на месте. Удалённые записи убираются после полного успешного поиска.
Для больших списков есть «Показать ещё», поиск работает по всему доступному списку. Запрос и фокус сохраняются при
поступлении результатов, в том числе новых путей уже показанного приложения.

## Надёжность и локальные данные

Перед добавлением из сохранённого списка SLX проверяет доступность файла. Программа, которая была удалена или
перемещена, не добавится с устаревшим путём; можно обновить список или выбрать актуальный `.exe`. Сам поиск не меняет
уже выбранные маршруты и не переподключает VPN.

Кэш защищён Windows DPAPI для текущего пользователя и хранится отдельно от подписки и настроек. Список программ не
отправляется на сервер. Повреждённый кэш не мешает запуску и свежему поиску. Обход папок ярлыков имеет общий лимит;
повторные обновления не создают очередь одновременных сканирований. Отмена и закрытие отбрасывают поздние результаты.

Обновление устанавливается поверх alpha.11 с сохранением настроек. В alpha.11 можно открыть «Настройки» и проверить
обновления. Приложение и установщик остаются без подписи; подпись производителя Wintun сохраняется. Сетевые правила,
протоколы, служба и серверы этим выпуском не меняются.

Проверено: locked restore, Release build без предупреждений, 330 unit/Windows-проверок и расширенный WPF-сценарий,
без ошибок и пропусков. Прямой поиск на текущем ПК: первый непустой результат за 100 мс, весь обход за 1866 мс;
это единичное наблюдение, не гарантия времени для других устройств. Снимки RU/EN на 940×660 и 1200×820 просмотрены.

Проверки и ограничения: [VERIFICATION.md](VERIFICATION.md). Устройство друга, Windows 10 и все реальные DPI/сценарии
обновления установленного клиента требуют отдельной приёмки.
