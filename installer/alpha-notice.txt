SLX VPN alpha.8 — Windows 10 / 11
Open source: https://github.com/Sooliks/slx-windows

Unsigned prerelease. Installs the SLXVPN service and vendor-signed Wintun.
If VPN fails, protected public traffic stays blocked while SLX reconnects. Use Disconnect to release protection.
LAN/loopback remain direct. Shared public DNS captured by TUN uses HTTPS via VPN; this is not per-app DNS isolation.
Use your own SLX device link; Happ bindings require official website transfer.
Full Windows 10, IPv6/HTTP3, existing-flow, sleep/network and clean-machine acceptance is pending.
Do not disable Windows security.

Предварительная версия без подписи SLX; официальный Wintun сохраняет подпись производителя.
При сбое защищённый публичный трафик блокируется до восстановления. Кнопка «Отключиться» снимает защиту.
Локальная сеть доступна напрямую; публичный DNS из TUN использует HTTPS через VPN.
Для Happ-ссылки нужен штатный перенос в кабинете. Полная системная приёмка ещё не завершена.
