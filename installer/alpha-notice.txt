SLX VPN 0.1.0 alpha — Windows 10 / 11
Open-source client: https://github.com/Sooliks/slx-windows

This is an unsigned early test release, not a fully accepted production client.
It installs the SLXVPN system service and the vendor-signed Wintun driver.
There is no kill switch: traffic may go direct if the VPN core stops.
Selected-app DNS uses the shared Windows resolver directly.
Use a separate SLX device link; an existing Happ binding must be transferred through the website.
Full TUN, sleep/resume, upgrade/uninstall and clean-machine acceptance is still pending.
Do not disable Windows security to run this installer.

Это ранняя тестовая версия без подписи SLX.
Она устанавливает системную службу SLXVPN и подписанный производителем Wintun.
Блокировки трафика при сбое VPN пока нет; DNS выбранных приложений проходит напрямую.
Для импорта используйте отдельную ссылку устройства SLX или штатно перенесите устройство из Happ.
Системные проверки маршрутизации, сна, обновления и удаления ещё не завершены.
